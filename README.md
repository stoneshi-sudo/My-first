# 三年级字词学习应用 📚

一个专为三年级学生设计的互动字词学习应用，支持 Notion 数据库集成，提供浏览、测验、复习等多种学习功能。

![应用截图](https://via.placeholder.com/800x400?text=三年级字词学习应用)

## 功能特性 ✨

### 核心功能

- 📖 **字词浏览** - 以卡片形式展示字词，包含拼音、释义和例句
- ✏️ **练习测试** - 随机生成测验题，支持多种题型和难度
- ⭐ **收藏复习** - 收藏重要字词，方便随时复习
- 📊 **学习统计** - 实时显示学习进度和正确率
- 🎨 **儿童友好** - 色彩鲜艳、操作简单，适合儿童使用

### Notion 集成

- ☁️ **云端数据** - 从 Notion 数据库实时加载字词
- 🔄 **自动同步** - 修改 Notion 数据库后自动更新
- 📝 **灵活配置** - 支持自定义字段映射
- 💾 **离线使用** - 未配置时使用示例数据

### 学习功能

- 🔍 **智能搜索** - 支持按字词、拼音、释义搜索
- 🏷️ **状态过滤** - 筛选已学习、未学习、收藏的字词
- 📈 **进度跟踪** - 记录学习状态和测验成绩
- 💪 **多种测验** - 释义选择题、拼音选择题等

## 快速开始 🚀

### 1. 使用示例数据

无需配置，直接在浏览器中打开 `index.html` 文件即可使用内置的 12 个示例字词。

### 2. 连接 Notion 数据库

#### 步骤一：创建 Notion Integration

1. 访问 [Notion Integrations](https://www.notion.so/my-integrations)
2. 点击 "New integration"
3. 填写名称，选择工作区
4. 复制生成的 "Internal Integration Token"

#### 步骤二：创建 Notion 数据库

在 Notion 中创建一个数据库，包含以下字段：

| 字段名 | 类型 | 说明 | 必需 |
|--------|------|------|------|
| 字词 | Title | 要学习的字词 | ✅ |
| 拼音 | Text | 汉语拼音 | ✅ |
| 释义 | Text | 字词的含义 | ✅ |
| 例句 | Text | 使用示例 | ✅ |
| 难度 | Select | 简单/中等/困难 | ⭕ |

**示例数据：**

| 字词 | 拼音 | 释义 | 例句 | 难度 |
|------|------|------|------|------|
| 欢快 | huān kuài | 形容高兴、愉快的样子 | 孩子们在操场上欢快地玩耍。 | 简单 |
| 勤奋 | qín fèn | 努力学习或工作，不懈怠 | 小明是个勤奋的学生。 | 简单 |

#### 步骤三：配置应用

1. 在 Notion 数据库页面，点击右上角的 "..."
2. 选择 "Add connections"，找到你创建的 Integration
3. 复制数据库 URL 中的 Database ID
   - URL 格式：`https://notion.so/workspace/数据库ID?v=...`
   - Database ID 是 URL 中的32位字符串
4. 在应用的"设置"页面，填入 Token 和 Database ID
5. 点击"保存配置"和"测试连接"

## 使用指南 📖

### 浏览字词

- 查看所有字词卡片
- 点击"收藏"按钮收藏重要字词
- 点击"已学习"标记学习进度
- 点击"详情"查看完整信息
- 使用搜索栏快速查找字词
- 使用过滤按钮筛选不同状态的字词

### 练习测试

1. 点击"练习测试"导航按钮
2. 选择题目数量（5题/10题/20题/全部）
3. 点击"开始练习"
4. 选择正确答案
5. 查看测验结果和正确率
6. 系统自动记录测验成绩

### 复习收藏

- 查看所有收藏的字词
- 支持收藏、取消收藏
- 标记学习状态
- 清空所有收藏

### 数据管理

- **重置进度** - 清除所有学习记录
- **导出数据** - 下载学习数据为 JSON 文件
- **Notion 同步** - 重新加载 Notion 数据库

## 技术实现 🛠️

### 技术栈

- **前端框架**: 纯 HTML/CSS/JavaScript（无依赖）
- **数据存储**: LocalStorage（本地）+ Notion API（云端）
- **UI 设计**: 响应式布局，支持移动端
- **样式方案**: CSS3 渐变、动画、Grid/Flex 布局

### 文件结构

```
.
├── index.html      # 主页面，包含所有界面结构
├── style.css       # 样式文件，儿童友好的配色方案
├── app.js          # 核心逻辑，包含 Notion 集成和所有功能
└── README.md       # 项目文档
```

### 数据流

```
Notion 数据库 ─────► Notion API ─────► 应用前端
                                        │
                                        ▼
                                   LocalStorage
                                   （学习进度）
```

### Notion API 集成

```javascript
// 查询数据库
POST https://api.notion.com/v1/databases/{database_id}/query

// 请求头
{
  "Authorization": "Bearer {token}",
  "Notion-Version": "2022-06-28",
  "Content-Type": "application/json"
}
```

## 常见问题 ❓

### Q: 如何添加更多字词？

**A:** 直接在 Notion 数据库中添加新行，应用会自动加载。

### Q: 数据会丢失吗？

**A:** 学习进度保存在浏览器本地，清除浏览器数据会丢失。建议定期使用"导出数据"功能备份。

### Q: 可以离线使用吗？

**A:** 已加载的数据可以离线使用，但需要联网才能从 Notion 同步新数据。

### Q: Notion 连接失败怎么办？

**A:**
1. 检查 Integration Token 是否正确
2. 确认 Database ID 是否正确
3. 确保数据库已添加 Integration 连接
4. 检查网络连接

### Q: 支持多人使用吗？

**A:** 每个浏览器独立存储学习进度，可以多人共享同一个 Notion 数据库但各自记录进度。
